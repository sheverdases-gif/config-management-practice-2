## Описание проекта

Данный проект представляет собой CLI-приложение для визуализации графа зависимостей пакетов.
На текущем этапе (Этап 1) реализован минимальный прототип с поддержкой настройки через опции командной строки.

## Описание функций и настроек

Приложение поддерживает следующие параметры командной строки:

- `--package` (или `-p`) — Имя анализируемого пакета (обязательный).
- `--repo` (или `-r`) — URL-адрес репозитория или путь к файлу тестового репозитория (обязательный).
- `--test-mode` (или `-t`) — Флаг включения режима тестирования (использовать локальный файл вместо URL).
- `--filter` (или `-f`) — Подстрока для фильтрации пакетов.

## Команды для сборки и запуска

Для запуска приложения используйте следующую команду:

```bash
python src/main.py --package express --repo https://registry.npmjs.org/express --filter dev
```
